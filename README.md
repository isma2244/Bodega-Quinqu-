# A Bodega do Quinqué — web estática

Web responsive preparada para publicar gratis en GitHub Pages, Cloudflare Pages, Netlify ou Vercel.

## Publicar en GitHub Pages
1. Crea un repositorio novo en GitHub.
2. Sube **todo o contido desta carpeta** á raíz do repositorio.
3. En **Settings → Pages**, escolle **Deploy from a branch**.
4. Selecciona a rama `main` e a carpeta `/ (root)`.
5. Garda. GitHub mostrará a URL pública cando remate o despregue.

## Música
A canción `assets/media/na-bodega-do-quinque.mp3` non tenta reproducirse antes da interacción do usuario. Ao pulsar **Entrar na bodega** comeza a volume baixo e non se repite automaticamente.
